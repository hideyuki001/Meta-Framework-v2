## **3.1 The Attractor Landscape**

### **What is an Attractor?**

In dynamical systems theory, an **attractor** is a state toward which a system naturally evolves, regardless of starting conditions within its basin.

**Physical Example:**

* A ball in a bowl will roll toward the bottom (attractor point)  
* Doesn't matter where you place it on the rim—it converges to center  
* The bowl's shape defines the **basin of attraction**

**Cognitive Example:**

* A conversation about "climate change" attracts toward political discourse  
* Even if you start with science, social context pulls toward policy/values  
* The semantic field creates attraction toward certain interpretive frames

```
            else:  
                force \= np.zeros(4)

        net\_force \= sum(gradients.values())

            position \= position \+ 0.1 \* net\_force  \# Step size \= 0.1  
            trajectory.append(position.copy())  
          
        return np.array(trajectory)
```

**Creative-Chaos**:

* Brainstorming mode

* Structure secondary to ideation  
* Example: "What if dogs could vote?" thought experiments

**Creative-Craft**:

* Polished creation mode  
* Controlled entropy  
* Structure serves aesthetic  
* Example: Writing polished fiction, crafting marketing copy

## **3.5 ECI as Transition Fuel**

ECI doesn't just measure quality—it **enables transitions**.

**Key Principle**: High ECI gives the system "permission" to move between attractors. Low ECI locks the system in place.
```
def can\_transition(current\_ECI, current\_attractor, target\_attractor):  
    """Does ECI support this transition?"""  
      
    \# Calculate transition difficulty  
    difficulty \= compute\_transition\_difficulty(current\_attractor, target\_attractor)  
      
    \# ECI must exceed difficulty threshold  
    threshold \= 0.55 \+ (difficulty \* 0.15)  
      
    if current\_ECI \< threshold:  
        return False, f"ECI too low ({current\_ECI:.2f} \< {threshold:.2f})"  
      
    return True, "Transition authorized"
```

## **3.7 Attractor Memory & Hysteresis**

### **Systems Remember Where They've Been**

**Hysteresis**: The system's current state depends on its history, not just present inputs.

**Example**:
```
Path A: Technical → Creative → Philosophical  
  └─ System is more likely to return to Creative than jump to Empathic

Path B: Technical → Empathic → Philosophical    
  └─ System is more likely to return to Empathic than jump to Creative
```
**Implementation**:
```
class AttractorMemory:  
    def \_\_init\_\_(self, memory\_depth=10):  
        self.history \= \[\]  
        self.memory\_depth \= memory\_depth  
      
    def add(self, attractor, timestamp):  
        self.history.append({'attractor': attractor, 'time': timestamp})  
        if len(self.history) \> self.memory\_depth:  
            self.history.pop(0)  
      
    def compute\_momentum(self):  
        """Which attractor has recent dominance?"""  
        if not self.history:  
            return {}  
          
        \# Weight recent attractors more heavily  
        weights \= np.exp(np.linspace(-2, 0, len(self.history)))  
          
        momentum \= {}  
        for i, entry in enumerate(self.history):  
            attr \= entry\['attractor'\]  
            momentum\[attr\] \= momentum.get(attr, 0\) \+ weights\[i\]  
          
        \# Normalize  
        total \= sum(momentum.values())  
        return {k: v / total for k, v in momentum.items()}  
      
    def bias\_transition(self, target\_distances):  
        """Adjust transition probabilities based on history"""  
        momentum \= self.compute\_momentum()  
          
        \# Attractors with recent momentum are "closer"  
        biased\_distances \= {}  
        for attractor, distance in target\_distances.items():  
            momentum\_bonus \= momentum.get(attractor, 0\)  
            \# Reduce effective distance by up to 30%  
            biased\_distances\[attractor\] \= distance \* (1 \- 0.3 \* momentum\_bonus)  
          
        return biased\_distances
```
**Effect**:

If the system has been in Creative attractor for several exchanges, transitioning back to Creative (even from a different attractor) becomes easier—the "path" is worn in.

This creates **attractor grooves**—preferred trajectories through phase space.
