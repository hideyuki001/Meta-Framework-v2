## ⚙️ Core Principles  

- **Amplification over Invention** — reveal and enhance what already exists.  
- **Constraint as Canvas** — use limitations as creative structure.

## 🔄 The ΔS Loop  

The framework operates on **ΔS (Creative Entropy)** —  
a measure of safe novelty and structural divergence.  

Each iteration flows through four recursive movements:  
1. **Evaluation →** fidelity, style, culture, safety  
2. **Induction →** emotional-symbolic expansion  
3. **Refinement →** synthesis, normalization, prosody  
4. **Re-evaluation →** creative fit and resonance  

When ΔS converges within threshold ε, the system achieves a *Resonant Equilibrium* —  
a state of coherence between cognition, feeling, and ethics.
